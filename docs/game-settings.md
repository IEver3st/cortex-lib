# Game settings

Cortex Settings contains library and registered script preferences only. There
is no Game settings tab, Key bindings link or return arrow to the quick menu.
Use GTA's native pause menu to change game preferences and controls.

The library does not read or write GTA preferences, embed its settings frontend,
or replace pause-menu movies. The retired Scaleform and keybinding bridges are
removed. Native menu handoff code remains for the optional quick menu's map and
keybinding shortcuts; see [pause behavior](pause-system.md).
